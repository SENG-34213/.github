# SENG 34213

## Building the future of learning with Mentify

Mentify is an AI-enabled Learning Management System that brings students, teachers, and administrators together in one connected learning platform.

Our goal is to make learning more accessible, engaging, and data-informed through practical education tools, intelligent assistance, and a reliable digital learning experience.

## What is Mentify?

Mentify brings the essential parts of modern learning into one platform:

- Course discovery and learning management
- Role-based dashboards for students, teachers, and administrators
- Assignments, quizzes, examinations, and grading
- Attendance and academic progress tracking
- Real-time communication and notifications
- Calendar and learning activity management
- AI-powered chat, quiz generation, and grading assistance
- Analytics and insights for better academic decisions

## Technology

Mentify is built with modern, production-oriented technologies, including:

- Java 17 and Spring Boot
- Spring Cloud microservices
- Next.js and TypeScript
- PostgreSQL and MongoDB
- Apache Kafka for event-driven communication
- Redis for caching and short-lived state
- Docker and GitHub Actions for delivery
- AWS services for deployment and content delivery
- OpenAI-powered features for intelligent learning support

## Architecture

Mentify is organized as a set of independently maintainable services. The frontend communicates with the backend through secure APIs, while backend services collaborate through synchronous service calls and asynchronous Kafka events.

This structure helps the platform evolve by keeping learning, communication, analytics, authentication, and AI capabilities separated into clear domains.
